# Acesso App

Aplicação mobile de gestão escolar desenvolvida em Flutter para utilização por instituições de ensino, com funcionalidades voltadas ao acompanhamento da vida escolar e à comunicação entre instituição, alunos e responsáveis.


## 📱 Sobre o projeto

O Acesso App foi desenvolvido como uma solução mobile para centralizar diferentes informações e serviços relacionados ao ambiente escolar.

Durante minha atuação no projeto, trabalhei no desenvolvimento e manutenção de funcionalidades da aplicação, participando de sua evolução técnica e da implementação de novas demandas.

Entre os principais recursos da aplicação estão:

- Acompanhamento de atividades escolares
- Consulta de informações acadêmicas
- Visualização e pagamento de boletos
- Avisos e comunicados
- Comunicação entre instituição, alunos e responsáveis
- Recebimento de notificações
- Integração com serviços externos

## 🔧 Minha atuação

Minha atuação no projeto envolveu principalmente o desenvolvimento e manutenção da aplicação mobile.

Entre as atividades realizadas:

- Desenvolvimento de novas funcionalidades, como a de pagamento
- Manutenção e evolução de funcionalidades existentes
- Integração com APIs REST
- Integração/Implementação de Firebase Cloud Messaging ao app, incluindo o backend
- Implementação e manutenção do gerenciamento de estado
- Desenvolvimento de interfaces utilizando Flutter
- Correção de problemas e ajustes de comportamento


## 🏗️ Arquitetura

A aplicação utilizava uma arquitetura organizada em diferentes camadas, buscando separar responsabilidades e facilitar a manutenção e evolução do código.

Entre os conceitos utilizados estavam:

- Separação entre apresentação, domínio e infraestrutura
- Repository Pattern
- Use Cases
- Data Sources
- Entities e Models
- Injeção de dependências
- Gerenciamento de estado


## 🔔 Notificações

Um dos recursos trabalhados no projeto foi a integração com Firebase Cloud Messaging (FCM), permitindo o envio de notificações para dispositivos dos usuários.

A implementação envolvia o tratamento da comunicação entre o backend, Firebase e aplicação Flutter para entrega das notificações.

Também montei o código em Python responsável pelas Push Notifications no backend.
